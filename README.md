# 오늘의 토플

열면 오늘 할 영어 한 바퀴가 바로 나오는 한 장짜리 연습 페이지.

- 주소: https://jun2peter.github.io/ENGLISH/
- 컨디션(5·25·50분)만 고르면 순서, 타이머, 과제가 정해진다.
- 문제는 구글 시트의 "문제" 탭에서 읽어 온다. 시트에 줄을 추가하면 다음에 열 때 반영된다. 어느 클로드에게든 시트 링크를 주고 "지시문 탭 읽고 문제 추가해줘"라고 하면 된다.
- 문제는 날짜가 아니라 진도로 나온다. 아직 안 푼 것 중 위에서부터. 며칠 쉬어도 이어서.
- 과제는 2026년 1월부터 바뀐 새 TOEFL iBT 유형(따라 말하기, 문장 조립, 인터뷰, 이메일, 학술 토론, 단어 완성)에 맞춘다. 듣기는 실제 음원 사이트 루틴으로.
- 기록은 그 기기의 브라우저에만 남는다. 공부한 날 끝에 "시트에 붙여넣을 오늘 줄 복사"를 눌러 시트의 기록 탭에 붙여 넣는다.
- 쓰기와 말하기 피드백은 복사 버튼이 만드는 글을 아무 클로드 창에나 붙여 넣으면 된다.
