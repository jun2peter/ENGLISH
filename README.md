# 오늘의 토플

열면 오늘 할 영어 한 바퀴가 바로 나오는 한 장짜리 연습 페이지.

- 주소: https://jun2peter.github.io/ENGLISH/
- 컨디션(5·25·50분)만 고르면 순서, 타이머, 과제가 정해진다.
- 과제는 2026년 1월부터 바뀐 새 TOEFL iBT 유형(듣고 따라 말하기, 문장 조립, 인터뷰, 이메일, 학술 토론, 단어 완성)에 맞춘다.
- 기록은 그 기기의 브라우저에만 남는다. 하루 끝에 "시트에 붙여넣을 오늘 줄 복사"를 눌러 구글 시트에 붙여 넣는다.
- 쓰기와 말하기 피드백은 복사 버튼이 만드는 글을 아무 클로드 창에나 붙여 넣으면 된다.
